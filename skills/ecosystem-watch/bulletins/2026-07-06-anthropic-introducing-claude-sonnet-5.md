## What Changed
Claude Sonnet 5 is now available at $2 per million input tokens and $10 per million output tokens (introductory pricing through August 31, 2026). It is the latest mid-tier Claude model and is available via the Claude API and Claude.ai.

## Impact on Agents
Agents that recommend model selection or configure LLM calls should consider Claude Sonnet 5 as the new default mid-tier option. The introductory pricing window closes August 31 — factor this into cost estimates. Check https://www.anthropic.com/news/claude-sonnet-5 for capability details before upgrading integrations.

## What Changed
Vercel introduced the Vercel Sandbox CLI, a command-line interface for managing isolated compute environments, built on the familiar Docker CLI model. Note: this entry was published November 2025 and was captured in this run as it was not in the previously-seen list.

## Impact on Agents
CICD and environment-management agents can now reference the Sandbox CLI for scripted sandbox orchestration without requiring the Vercel dashboard. Check https://vercel.com/changelog/vercel-sandbox-cli-is-now-available for CLI reference before building sandbox automation.

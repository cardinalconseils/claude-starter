## What Changed
Claude Opus 4.5 from Anthropic is available in Vercel AI Gateway with BYOK support, no markup on provider pricing, and high rate limits. Full details at https://vercel.com/changelog/claude-opus-4-5-now-available-in-vercel-ai-gateway.

## Impact on Agents
CKS projects routing Claude calls through Vercel AI Gateway can access Opus 4.5 as a model option. Check https://vercel.com/changelog/claude-opus-4-5-now-available-in-vercel-ai-gateway for model IDs and configuration before updating gateway routing rules.
